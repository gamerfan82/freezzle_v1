Implement a server-authoritative Dealer status transition policy.

```text

```

and directly change their own status.

* PENDING
* APPROVED
* REJECTED
* SUSPENDED

For example:

```text

```

Do not blindly implement this exact matrix if the existing business rules differ.

Invalid transitions must return an appropriate error.

# 10. SUSPENDED DEALER AUTHORIZATION

This is a critical security requirement.

A dealer with:

```text

```

must not be able to continue using dealer privileges merely because they already possess a valid JWT.

Inspect the existing JWT/session architecture.

Implement the smallest safe solution.

Possible strategies include:

* status check during authenticated dealer operations
* status validation in the appropriate guard/service
* session revocation when suspended

Do not blindly revoke all User sessions unless that matches the existing authentication design.

Do not break normal USER authentication.

```text

```
